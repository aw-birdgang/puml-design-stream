# 로그인 · KYC 인증 기획서 상세 요약

이 문서는 로그인 및 고객확인(KYC) 인증 기획서를 기반으로 한 **핵심 요약**을 개발 및 운영 관점에서 상세히 정리한 것입니다.

---

## 1. KYC 플로우 (모바일 우선)
- **단계**:
  1. 본인확인 (CI/휴대폰 인증)
  2. 고객정보 입력
  3. 신분증 인증 (OCR, Liveness Detection)
  4. 계좌 인증 (1원 송금 또는 은행 API)
- **부가 기능**:
  - KYC 중단 후 재개 기능 (유효기간 내)
  - 법적 고지 및 동의 수집 (필수/선택)
  - PC에서는 STEP3/4 불가 → 모바일 앱/웹 딥링크 유도
- **UI**:
  - 데드라인 D-day 표시
  - CTA 버튼을 통한 즉시 이행 유도

---

## 2. KYC 상태 및 제한
- 상태 분류:
  - 미실시: 거래/입출금 불가
  - 기간 도래: 거래/입출금 가능, D-day 안내
  - 강제 재이행: 거래/입출금 불가
  - 심사대기: 거래/입출금 가능 또는 불가 (정책에 따라 다름)
  - 완료: 정상 이용 가능
- 재이행 팝업:
  - 마감 4시간 전 → 매매 제한, 미체결 주문 자동 취소
  - 마감 1시간 전 → 입출금 제한

---

## 3. 보안 센터 (Security Center)
- 기능:
  - 해외 로그인 차단 (Geo-IP 기반)
  - 로그인 이력 조회 (디바이스, IP, 위치 표시)
  - 원격 로그아웃 (세션 무효화)
  - 출금 시 OTP(2차 인증) 요구
  - KYC 상태 배너 노출

---

## 4. 레거시 계정 활성화 (휴대폰 인증 없이 가입된 계정)
- 절차:
  - 이메일 본인확인 (OTP)
  - 본인 명의 휴대전화 인증 (CI)
  - 고액 보유 계정(예: 100만원 이상)은 고객센터 경유만 허용
- 완료 시: 재로그인 필수

---

## 5. 이메일 찾기 및 비밀번호 재설정
- 이메일 찾기:
  - 휴대폰 명의 인증 후 계정 목록 제공
- 비밀번호 재설정:
  - 선택한 계정 → 이메일 OTP 발송
  - 새 비밀번호 입력 후 재로그인
- 예외 처리:
  - 인증번호 오류/만료 시 메시지 노출 및 타이머(3분) 리셋

---

## 6. 다계정 통합 (1인 1계정 정책)
- 절차:
  - 주계정 이메일 인증 후 통합 진행
  - 부계정 자산 → 주계정으로 이관
  - 부계정 미체결 주문 자동 취소 및 계정 탈퇴 처리
- 정책:
  - 통합 후 재로그인 필요
  - 복구/재가입 불가
  - 정책 문구 및 자산 산정 기준 안내

---

## 7. 개명 신청 (이름 변경)
- 사용자 제출:
  - 주민등록초본 (주민번호 뒷 6자리 마스킹, 발급일 3개월 이내)
- 프로세스:
  - 동의 수집 후 심사팀 검토
  - 승인 시 → 이름 변경 + 미체결 주문 취소 + KYC 재등록 요구
  - 반려 시 → 사유 제공

---

## 8. 회원 탈퇴 (잔고 조건 포함)
- 조건:
  - 잔여 보유 자산 1만원 이상 → 탈퇴 불가, 자산 출금 안내
  - 잔여 보유 자산 1만원 미만 → 소액 자산 권리 포기 동의 후 진행 가능
- 제약:
  - 탈퇴 후 24시간 내 재가입 불가
  - 반복 재가입 시 제한 (1년 내 3회 이상 금지)

---

## 9. 개인정보 제3자 제공 (Travel Rule)
- 목적: 가상자산 송수신 시 송·수신자 정보 확인
- 대상: VerifyVASP Pte. Ltd
- 항목: 송수신자 정보, 거래 내역
- 보관기간 및 동의 고지 포함

---

## 10. 개발 체크리스트
- 재이행 스케줄러 구현 (T-4h/T-1h 제한 자동화)
- 계정 통합/탈퇴/개명 시 **미체결 자동 취소** + 세션 무효화
- PC → 모바일 딥링크 가드 적용
- 보안센터 전용 API (Geo-IP, 세션 관리, OTP) 구성
- 레거시 계정 활성화 정책(자산 기준 분기 처리)
